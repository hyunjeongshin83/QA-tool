# 츄구미 점검 도구 (ChewGumi QA Kit)

화면 위에 노란 메모지를 띄워, 이상한 곳을 짚어 보내는 도구입니다.
**어느 웹사이트에나 붙일 수 있습니다.**

---

## 무엇을 하나

**콕 집기** — 이상한 곳을 누르면 무엇을 짚었는지 자동으로 적힙니다
**캡처** — 지금 화면을 사진으로 담습니다. 길게 누르면 전체 페이지
**값 채우기** — 이름·연락처·주소 등 모든 입력칸을 자동으로 채웁니다
**화면 읽기** — 작은 글씨, 안 뜨는 이미지, 누르기 힘든 버튼, 화면 넘침을 찾습니다
**자동 검증** — 그 화면이 제대로 작동할 준비가 됐는지 확인합니다

---

## 붙이는 방법

### 1. 파일 올리기

`assets/` 폴더의 다섯 파일을 사이트에 올립니다.

```
qa-on.js      점검 모드 유지 (한 번 켜면 계속)
qa-pad.js     메모지 본체
qa-fill.js    입력칸 자동 채움
qa-mode.js    역할 전환
qa-report.js  접수 전송
```

### 2. 화면에 연결

각 페이지의 `</body>` 앞에 넣습니다.

```html
<script src="assets/qa-on.js"></script>
<script src="assets/qa-pad.js" defer></script>
<script src="assets/qa-fill.js" defer></script>
<script src="assets/qa-mode.js" defer></script>
```

### 3. 켜기

주소 뒤에 `?qa=1` 을 붙여 한 번 들어가면 됩니다.

```
example.com/index.html?qa=1
```

이후에는 다른 화면으로 옮겨도 메모지가 따라다닙니다.
끄실 때는 `?qa=0` 입니다.

## 접수함 만들기

메모지가 보낸 내용을 받을 곳이 필요합니다.

### Supabase 를 쓰는 경우

`server/schema.sql` 을 SQL 편집기에 붙여넣어 실행하세요.
표 하나와 권한이 만들어집니다.

`server/qa-server.ts` 는 Edge Function 으로 올립니다.

```bash
supabase functions deploy qa --no-verify-jwt
```

### 다른 서버를 쓰는 경우

`qa-pad.js` 안의 주소만 바꾸시면 됩니다.

```js
var SB  = 'https://내서버주소';
var KEY = '내키';
```

받는 쪽은 아래 형태의 JSON 을 처리하면 됩니다.

```json
{
  "page": "index.html",
  "kind": "기타",
  "note": "여기 글씨가 작습니다",
  "shot": "data:image/jpeg;base64,...",
  "viewport": "390x844",
  "device": "iPhone"
}
```

## 코드 없이 쓰기

사이트를 고칠 수 없을 때는 **북마클릿**으로 쓰실 수 있습니다.

브라우저 즐겨찾기에 아래를 주소로 등록하세요.

```
javascript:(function(){var s=document.createElement('script');s.src='https://내주소/assets/qa-pad.js';document.body.appendChild(s);})();
```

보고 싶은 화면에서 그 즐겨찾기를 누르면 메모지가 뜹니다.

## 화면 읽기가 찾아내는 것

**글자**
- 너무 작은 글씨 (모바일 12px · PC 11px 미만)
- 줄 간격이 좁아 읽기 힘든 문단

**이미지**
- 안 뜨는 이미지
- 설명(alt)이 없는 이미지
- 크기가 지정되지 않아 화면이 튀는 이미지
- 비율이 맞지 않아 찌그러진 이미지
- 화소가 모자라 흐릿한 이미지 (레티나 기준)
- 원본이 지나치게 큰 이미지

**버튼**
- 이름이 없는 버튼
- 손가락으로 누르기 작은 버튼 (모바일 44px 미만)

**입력칸**
- 무엇을 넣는지 안내가 없는 칸
- 글씨가 16px 미만인 칸 (아이폰에서 화면이 확대됩니다)

**배치**
- 가로로 넘쳐 좌우로 밀리는 요소
- 아이폰 홈 인디케이터에 가리는 버튼

## 값 채우기

**모든 입력칸을 채웁니다.** 무엇을 넣는 칸인지 알아보고 그에 맞는 값을 넣습니다.

이름·연락처·이메일·주소는 실제 형식에 맞게,
숫자·날짜·시간은 형식에 맞는 기본값으로,
선택 상자는 첫 번째 실제 항목으로 고릅니다.

**알아보지 못한 칸도 비우지 않습니다.** 형식만 보고 알맞은 값을 만듭니다.
